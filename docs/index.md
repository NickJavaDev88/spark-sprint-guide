## How to use this guide

1. Read [The event](./event) once (5 minutes) so you know what is expected and what is not.
2. Do **Block 0** of the [30-hour plan](./plan) tonight: accounts, fork, and start the Spark build in the background.
3. Follow the blocks in order. Each one ends with a "done when" test so you know when to move on.
4. Use the [Spark setup checklist](./setup) on the last morning to verify everything works before you leave.
5. Keep [Resources](./resources) open for the links.

> **Unofficial.** This is a community study guide. It is not affiliated with PyCon TW, the Apache Software Foundation or the Apache Spark project. Dates, requirements and commands were checked against the official pages on **2026-10-08**; always re-check the official sources for last-minute changes. Items marked "verify" were not confirmed and should be checked in the repository you cloned.
