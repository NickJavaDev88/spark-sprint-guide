## Sobre esta guía

Los datos del evento y del proceso de contribución a Spark se comprobaron el 2026-10-08 contra el HackMD oficial, la guía de contribución de Spark, la guía de testing de PySpark y el índice de contribución de Airflow. **No** se abrieron las subpáginas de Airflow, el script de lint de Spark, su archivo de requisitos de Python ni el script de coverage; donde aparecen están marcados como "verifica".

Las correcciones y traducciones se agradecen como pull requests.
