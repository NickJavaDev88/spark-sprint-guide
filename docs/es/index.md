## Cómo usar esta guía

1. Lee [El evento](./event) una vez (5 minutos) para saber qué se espera y qué no.
2. Haz el **Bloque 0** del [plan de 30 horas](./plan) esta noche: cuentas, fork y lanzar la compilación de Spark en segundo plano.
3. Sigue los bloques en orden. Cada uno termina con un "hecho cuando" para saber cuándo pasar al siguiente.
4. Usa la [checklist de Spark](./setup) la última mañana para comprobar que todo funciona antes de salir.
5. Ten a mano los [Recursos](./resources) para los enlaces.

> **No oficial.** Es una guía comunitaria de estudio. No está afiliada a PyCon TW, a la Apache Software Foundation ni al proyecto Apache Spark. Fechas, requisitos y comandos se comprobaron contra las páginas oficiales el **2026-10-08**; vuelve a mirar las fuentes oficiales por si hay cambios de última hora. Lo marcado como "verifica" no se pudo confirmar y debe comprobarse en el repositorio que clones.
